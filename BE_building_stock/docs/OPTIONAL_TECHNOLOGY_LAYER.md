# Optional technology assignment layer

## Isolation from the core model

The core building-stock pipeline ends at the 2050 renovation-state matrix. The
technology module reads that matrix and creates separate heating, cooling and
PV assignment variants. Core envelope states, renovation priorities and
heating/cooling demand calculations have no dependency on these assignments.

The module is retained for later sensitivity work. Its evidence snapshot has a
2024 observation vintage and is identified by
`data/raw/technology/technology_source_snapshot_2024.csv`. Newer reporting can
be incorporated through a dedicated update before the layer is used for thesis
results.

## Run separately

From `BE_building_stock`:

```bash
npm run technology:optional
```

The command requires a current two-scenario renovation matrix generated by
`npm run renovation`.

## Outputs

| Output | Rows | Meaning |
| --- | ---: | --- |
| `data/scenarios/technology/archetype_heating_system_layer_2050.csv` | 1,350 | Regional carrier variants for Existing/Standard rows and one heat-pump package for Advanced rows. |
| `data/scenarios/technology/archetype_cooling_adoption_layer_2050.csv` | 2,700 | Two cooling variants under three adoption cases for every state row. |
| `data/scenarios/technology/archetype_pv_assignment_layer_2050.csv` | 900 | PV and no-PV variants for every state row. |

## Evidence boundary

- Heating-carrier shares use BE-SILC 2022 regional observations.
- Active-cooling ownership uses Statbel Household Budget Survey 2024 results.
- PV inputs use a versioned set of regional 2024 observations, proxies and
  2030 policy trajectories.
- Technology packages and future adoption rates are model assumptions.
- Efficiencies, COP, SEER, useful energy, final energy, PV generation and grid
  effects belong to the downstream thermal-demand and energy-system model.

The full field-level classification and source registry are stored in
`data/assumptions/technology/technical_systems_metadata.yaml`. The technology
snapshot is included in `data/provenance/source_integrity_sha256.csv` and is
labelled `optional_technology`.
